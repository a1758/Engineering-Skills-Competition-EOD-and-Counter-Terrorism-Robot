# 独立二维码识别

程序：`test/qr_standalone.py`。在 OpenMV IDE 中打开并运行，不依赖 main.py。

## 测试模式

默认 `RUN_MODE = "TEST"`，VGA 640×480 全画面扫描，不初始化串口。
同一个有效二维码在 1500 ms 间隔内识别两次后，终端打印 `QR LOCKED`。
有效内容为三位数字，每位只能是 1、2、3。
画面显示当前命中、确认次数及最近确认的内容；最近结果保留不代表当前仍能识别。
按真实起点摆放小车，分别测试二维码偏左、正中和偏右的情况。

## 联调模式

设置 `RUN_MODE = "LINK"`。UART1，115200，8N1：P1 TX 接 STM32 PD9 RX，
P0 RX 接 STM32 PD8 TX，两端共地。

1. STM32 停稳后发送 ASCII `qr\r\n`。
2. OpenMV 扫描并确认二维码，保存内容到本程序变量 `locked`。
3. OpenMV 回复 ASCII `finishqr\r\n`，不发送二维码内容，符合固定路线二维码握手。
4. 再次收到 `qr` 会重发已完成的回复。重新识别新二维码前发送 `reset\r\n`，再发送 `qr\r\n`。

程序不会自动发送 `start`。它只验证二维码环节，不运行后续颜色识别或比赛任务。
它与示例代码中的 UART3、A3 B3 二进制包协议不同。

## 硬件配置

默认按 main.py 的接线控制 P7 相机俯仰至 10°、P9 补光使能。
仅连接摄像头测试时，将 `PITCH_ENABLE` 和 `LIGHT_ENABLE` 改为 `False`，手动摆好相机。
相机翻转与 main.py 一致，默认 `CAMERA_ROTATE_180 = False`；图像倒置时改成 `True`。
全画面扫描能够覆盖偏左二维码；二维码过小、模糊或严重斜视仍可能无法解码。
