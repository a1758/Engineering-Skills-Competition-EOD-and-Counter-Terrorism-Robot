# 主程序使用已验证激光与串口配置

已根据 test/laser_test.py 和 test/uart_light_test.py 更新 main.py。

- UART1，115200、8N1；timeout=20、timeout_char=20、read_buf_len=256，沿用成功测试的参数。
- STM32 PD8（USART3 TX）接 OpenMV P0（UART1 RX）。STM32 PD9（USART3 RX）接 OpenMV P1（UART1 TX），两板共地。转接板4针接口：1脚P1 TX、2脚P0 RX、3脚GND、4脚5V。旧文档中P0 TX/P1 RX说法错误，以这里为准。
- 激光控制线P6，Pin.OUT_PP，高电平开、低电平关；上电初始化保持关闭，靶色匹配、连续锁定及瞄准条件满足后，按LASER_ON_MS开启。模式切换、目标丢失、脉冲到期、异常退出时关闭。
- P9补光灯保留全程常亮，不采用握手测试里的延迟关灯动作。

激光常亮测试只验证电气控制，不代表瞄准标定完成。LASER_AIM_CALIBRATED=False保留；测量实际激光点对应的图像中心及容差，填写LASER_AIM_WINDOW，确认后设置True。未标定会发事件15，不会开激光。抓取标定状态也保留。

正式程序保留VIS V3（32字段）、VCMD/VACK/VEVT及CRC协议，不发送openmvtest、不等待open，不混入测试字符串。STM32必须退出ROBOT_OPENMV_UART_TEST_MODE并接入正式协议，才能驱动任务状态机。串口握手成功只能说明物理链路和测试指令有效，不能证明正式协议已对接。

激光定时由主循环执行，在抓图前后及视觉处理开始处检查。阻塞的图像运算可能延后关闭时间；不是独立硬件定时截止，LASER_ON_MS不保证严格上限。
