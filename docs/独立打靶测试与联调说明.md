# 独立打靶测试与 OpenMV—STM32 联调流程

程序：`test/target_shoot_standalone.py`。它复用 `main.py` 的 QVGA、LAB 颜色阈值、TARGET 俯仰姿态和 P5 激光控制，但不执行完整路线，也不控制底盘电机。

## 一、职责和时序

1. STM32 行驶到靶位并停车，发送 `target`。
2. OpenMV 设置 P7 俯仰云台到 `PITCH_TARGET_DEG`，等待稳定；识别 `TARGET_COLOR` 指定颜色。
3. 目标必须连续 `CONFIRM_FRAMES` 帧，ROI 内只有一个候选并满足瞄准条件。随后 OpenMV 发送 `stop`，STM32 保持底盘暂停并执行写死的打靶动作；不传坐标。
4. OpenMV 打开 P5 激光，持续 `LASER_ON_MS` 毫秒后强制关闭，并发送 `laser`。该消息只表示激光脉冲开始，不代表命中。
5. STM32 完成自己的命中判定后发送 `finishtarget`。OpenMV 关闭激光、发送 `ready`，退出打靶模式，等待下一次 `target`。
6. STM32 完成固定打靶动作及夹爪水平云台右转 90°后发送 `finishtarget`；OpenMV 回复 `ready`，退出打靶模式。

所有换行均为 `\\r\\n`，UART 默认 UART1、115200-8-N-1，与 `main.py` 接线保持一致。若主工程使用 CRC `VCMD/VEVT` 帧，应在 STM32 适配层把这些测试文本映射为现有事件：`stop` 对应停车/保持，`laser` 对应激光开始；`finishtarget` 由 STM32 在打靶及后续动作完成后发送。

## 二、DEBUG 模式

将 `RUN_MODE = "DEBUG"`。不依赖 STM32：识别成功后把底盘停车视为已完成，激光脉冲结束后自动模拟 `finishtarget`，串口只打印 TX/RX。适合先验证颜色阈值、俯仰角、激光电平和瞄准窗口。

建议顺序：先断开激光或拔掉激光供电，仅看画面框和串口；确认目标框稳定后，再接入激光并把 `LASER_ON_MS` 设为较小值；最后实测激光点位置并填写 `AIM_CENTER` 与容差。

## 三、INTEGRATION 模式

将 `RUN_MODE = "INTEGRATION"`，OpenMV 与 STM32 共地并交叉连接 UART。STM32 只在底盘真实停稳后发送 `target`，不要用延时伪造到位。STM32 收到 `stop` 后保持电机停止并执行固定打靶动作，收到 `laser` 不得当作命中；命中判定完成后才发送 `finishtarget`。打靶及水平云台动作全部完成后才发送 `finishtarget`。

联调检查点：

- 上电后激光应为关闭；任何丢目标、模式切换、复位和异常都应保持关闭。
- 多个色块、颜色不符、目标未稳定或未进入瞄准窗口时，OpenMV 不开激光。
- `STOP` 只请求/确认停车，OpenMV 不发送底盘速度。
- `laser` 是开始脉冲通知，不能代替 STM32 的完成通知。
- `ready` 只表示 OpenMV 已退出打靶模式，可以进入下一阶段。
- 下一靶位必须重新发送 `TARGET 20/21/22`，脚本不会自动重复开激光。

## 四、标定参数

先在实物停车位置采集图像，重新标定 `COLORS`、`OBJECT_ROI`、`PITCH_TARGET_DEG`。确认激光点与靶心重合后填写 `AIM_CENTER` 和 `AIM_TOLERANCE`。确认 P5 为高电平开、低电平关；若激光模块为反相输入，修改 `laser.high()/low()`。

脚本中的 `TARGET_COLOR=1/2/3` 分别对应红/绿/蓝初始阈值，阈值仅作起点，必须按现场光照复测。P7 是俯仰云台，水平夹爪云台由 STM32 控制，OpenMV 不输出其 PWM。
