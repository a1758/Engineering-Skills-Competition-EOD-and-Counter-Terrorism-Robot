# 路线视觉双向接口（OpenMV已实现，STM32需新增）

同一个UART1/USART3，115200 8N1。P0 RX接PD8 TX，P1 TX接PD9 RX，共地。

现有ACTIONS_V2的换行文本云台命令及BUSY/DONE/ERROR保留；另外新增下列CRC帧。STM32需按首字符区分：$开头按#结束的视觉帧，其余按换行解析动作文本。不得将视觉帧误当作动作命令。

## 帧格式

`$BODY*CCCC#`，CCCC为BODY的ASCII字节CRC16/CCITT-FALSE，初值FFFF、多项式1021、无反射、无末尾异或，4位大写十六进制。校验样例123456789=29B1。

STM32先发送command3（PING），OpenMV回复VACK后开启VIS/VEVT发送，避免向未升级的动作固件持续发送未知数据。亦可首条发送合法到站指令。命令状态非0时不启用。

STM32发送BODY：`VCMD:1,seq,command,arg`。seq为0..65535；重发同一命令用同一seq，改内容用新seq。近期8条去重，禁止一个编号复用为不同内容。

|command|arg|用途|
|---|---|---|
|3|0|PING/启用视觉数据发送|
|4|到站码|底盘停稳，相关机构完成后切换模式|
|5|事件ID|确认收到并接管普通任务事件|
|6|0|球桶对齐且锁定后允许松爪|
|7|0或1|旧拐角检测开关；新版主要用每段CORNER_END_LIMITS|
|1|模式0..6|架空/固定车调试视觉模式，不用于绕过任务条件|
|2|0|重置任务，运动时不接受|

回复BODY：`VACK:1,seq,status,mode`，status0=接受、1=拒绝。尚有任务事件未确认、抓取动作进行中等情况下会拒绝到站。运动云台时模式/重置/到站/放球请求不接受，需DONE后用同一编号重试。

云台事件18/6/7/5专由ACTIONS_V2动作DONE完成，不接受远端command5直接确认。普通事件ACK表示STM32已接管事件，不代表底盘运动已经完成。事件重复到达须按ID去重，不重复开车。

## 到站码与视觉模式

1=二维码；10/11/12=小球；20/21/22=靶子；30/31/32=人质；40=第二球位；41=球桶朝向完成；42=放球后朝向完成；50=打靶完成；60=紫区停车完成；61=人质抓取后回正完成。

70=第一平移停、71=左转完成开始侧缘段；72=第一直行停、73=回正完成开始前缘段；74=第二平移停、75=左转完成开始第二侧缘段；76/78=两个拐角停车；77/79=对应云台及底盘转向完成；80=首靶停车请求左180°。完整语义见新版路线寻边说明.md。

首段二维码示例BODY顺序：PING -> 到站1 -> 接收并ACK事件1（二维码已保存） -> 接收并ACK事件17（参考就绪） -> STM32允许开始第一段平移 -> 停稳后到站70。二维码读出、参考就绪不能合并为一个放行条件。

## OpenMV结果

VIS:3共有32整数，字段位置见新版路线寻边说明.md。字段8只发送判定0未知/1正确/2错误；不发送任务颜色、形状编号。字段16偏差px、17图像倾角乘100；27=0双边居中/1前缘/2侧缘，28=路线段；29/30=边缘y/参考y；31=参考采集中。无效有符号字段-32768，不得当成真实控制值。

字段3 flags：bit0有效、bit2姿态就绪、bit5停车要求、bit6过期。仅有效、姿态就绪、非过期、非停车要求且处于许可行驶段时使用纠偏。

CENTER正偏差表示轨道中心在画面参考右侧。FRONT/SIDE正偏差表示边缘y大于参考y。倾角都是图像角度，不是物理车身航向。侧视左右方向、平移/直行的轴映射必须逐段实测。STM32负责限速、死区、限幅、滤波及控制参数，不能直接把像素或角度数值当轮速。

STM32应在有效视觉消息持续缺失超过200ms时减速/停车，bit5置位时停车；云台动作进行中不应用巡航数据。未知识别结果不是错误目标，不得直接去下一个站。

VEVT BODY：`VEVT:1,event_id,action,arg`，持续发送到ACK。主要action：1二维码存好；2错误目标、arg下一目标位置；3激光脉冲开始（非命中证明）；4球已执行夹取、arg返回第二球位；9终点完成；10全不匹配；11微调；12夹取未标定；13识别超时；14拐角停车；15激光未标定；16紫区减速；17寻边参考就绪、arg路线段；19紫区停车请求。

夹取完成目前仅证明舵机控制等待结束，无夹持传感器。激光命中确认、实际到站、紫区停稳由STM32负责，不得以事件3/19代替。

## 实测顺序

架空车先测PING/VACK、分段接收、错误CRC丢弃、重复命令不重复执行。固定车发到站1，测试二维码到TRACK及事件1/17握手。再分别发小球、靶子、人质到站码测试正确/错误/未知。最后低速验证每段纠偏正负方向、丢边停车、断线超时停车。STM32接口未升级前不能跑完整自动路线。
